# Ahmad-AI Project Charter

## Vision
Build a trustworthy, local AI platform that prioritizes truth, transparency, and modularity.

## Mission
Develop a local AI system capable of supporting multiple domains through verified knowledge sources, beginning with an Islamic study assistant.

## Objectives
- Run completely on local hardware.
- Use open-source language models.
- Minimize hallucinations.
- Prefer evidence over confidence.
- Support multiple knowledge domains.
- Be modular and maintainable.

## Engineering Principles
1. Truth before fluency.
2. Never fabricate sources.
3. Say "I don't know" when uncertain.
4. Separate the AI engine from the knowledge base.
5. Keep the system modular.
6. Version every meaningful change.

## Initial Technology Stack
- Windows 10 Pro
- Ollama
- Llama 3 8B
- Git
- Markdown Documentation
